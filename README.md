# Multi Account

Клиентский Fabric-мод для быстрого переключения между оффлайн-аккаунтами и запуска нескольких копий игры одновременно.

## Клавиши

| Клавиша | Действие |
|---|---|
| F9 | запустить следующий аккаунт из списка |
| F10 | открыть меню аккаунтов |
| F8 | переключиться на окно другого запущенного аккаунта |

Клавиши меняются в `config/multiacct.json`.

## Как работает

- Аккаунты хранятся в `config/multiaccount/accounts.json`.
- Если аккаунт уже запущен — мод не поднимает второй процесс, а переводит фокус на его окно.
- Каждый запущенный инстанс пишет свой лог в `config/multiaccount/logs/`.

## Ограничения

- Работает только на Windows (переключение окон через `user32`).
- Вход оффлайн: `--accessToken 0`, `--userType legacy`. На серверах с премиум-авторизацией не пустит.
- Все инстансы используют один `gameDir`, поэтому настройки, сохранения и логи у них общие.
